## G. Query contract

- `LAB_QUERY_SCHEMA_VERSION = 1`, versioned separately from `LAB_PROJECTION_SCHEMA_VERSION = 1`. An unknown query
  version is refused by the validator AND independently by the engine.
- Fields and operators: `lib/lab/fields.mjs` (the table is in `docs/RESEARCH_LAB.md` §6). Team-relative fields
  (`result`, `homeAway`, `scored`, `allowed`, `opponentId`) refuse without a team — `FIELD_REQUIRES_TEAM`.
- Budgets: 8 filters · 2 sorts · 4 entities · 500 returned rows (hard cap) · page 25/50/100 · **1 row partition** ·
  1,024-character URL.
- 18 refusal codes, each with exactly one sentence; an unknown code throws rather than rendering nothing.
- Filters are AND. There is no OR tree, no nesting, no expression, no user-authored formula, no SQL.

## H. URL and share contract

- Fixed parameter order ⇒ one logical query has exactly one canonical URL; a scrambled input serializes back to it
  and `parse → validate → serialize → parse` is a fixed point.
- Identity is the exact index slug. A display name, a case variant, a prefix and the raw canonical id are all
  invalid. Search finds a candidate; selection writes that row's slug.
- Unknown query keys are ignored (a tracking parameter must not break a shared link); a KNOWN key with an
  unreadable value is an error with a code, never a guess and never a silently dropped clause.
- `switchTarget` is the one place state is removed, and only because the reader chose a different search: the sport
  is kept when the new mode ships it, sport-specific state is dropped, a sort key survives when the new mode offers
  it, and the page size belongs to the reader.

## I. Missingness and identity

`null` never matches a numeric comparison — **not even `>= 0`** — and is never read as 0; a recorded `0` is a value.
A player-game that does not record the selected family is not an answer and not a zero. A game id appears once; an
MLB doubleheader stays two ids. A player row's team is THAT game's team, never the current roster. Same-name people
stay two ids and two slugs. A cross-sport id is refused. A host that the source does not prove is Neutral on both
sides and can never match Home or Away.
