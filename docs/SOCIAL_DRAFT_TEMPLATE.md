# Social Draft Template

*Every social draft uses this block. It stays a draft until the Social Media Head reviews it and Yash
approves it. No draft may claim real money, promise profit, or hide a loss. See
[SOCIAL_OPERATIONS.md](SOCIAL_OPERATIONS.md).*

```
SOCIAL DRAFT — <date>
Channel:              Discord | Instagram | TikTok | X/Twitter
Angle:                <the honest hook — slate drop / results recap / milestone / how-the-model-called-it / honest miss>
Source fact:          <the exact settled/canonical fact this is built on — record, score, milestone; where it came from>
Draft copy:           <the post text — responsible, no hype, no real-money framing, no guarantees>
Asset concept:        <visual/clip idea — deterministic, on-brand, sportsbook-inspired but paper-only; no fabricated assets>
Responsible-copy check:
  [ ] no hype / no "lock" / "guaranteed" / "risk-free" / "sure thing"
  [ ] no real-money betting framing (paper-only, educational)
  [ ] no promised profit / no guarantee
  [ ] losses shown honestly (not hidden or spun)
  [ ] source fact is real (settled/canonical), not fabricated
Status:               DRAFT | HEAD-REVIEWED | YASH-APPROVED
```

**Flow:** manager fills it in (DRAFT) → Social Media Head runs the check + merges (HEAD-REVIEWED) → Yash
approves in the packet (YASH-APPROVED). Only a YASH-APPROVED draft may be posted, and only manually until
approved posting tooling exists.
