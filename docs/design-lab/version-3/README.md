# Design Lab V3 — Mobile Sports App
- **Preview route:** `/design-lab/v3`
- **Thesis:** one-thumb feed. Swipeable sport chips, compact feed cards, sticky icon bottom nav, dark + violet.
- **Best pages:** daily habit / Today, quick checking, fast route switching.
- **Weak pages:** lower information density for power users.
- **Mobile:** primary target — sticky header chips + bottom nav; verified 390px, no overflow.
- **Reusable in final:** the sport-chip switcher, the icon bottom nav, the compact feed-card pattern.
- **Data:** real (UFC settled feed card, Bank Builder card, MLB slate card).
