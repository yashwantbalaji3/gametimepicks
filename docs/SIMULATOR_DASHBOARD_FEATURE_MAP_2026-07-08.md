## 1. Product goal

Move the simulator from **"a game report with a simulation button"** to a **"simulation-first dashboard with the model report beneath it."** A user picks a game → clicks Generate Simulation → watches a 10s+ sport animation → sees a full, honest model dashboard built entirely from the precomputed deterministic artifact (`public/data/mlb/game-simulations/<date>.json`).

## 3. Soccer modules — explicitly deferred (NOT supported for MLB, NEVER faked)

The screenshots are soccer-heavy. These are **not generated by the MLB artifact** and must render as honest unavailable states, never fabricated: **first goal scorer, corners, team goal totals, exact scoreline, half results, Asian handicap, BTTS, cards, xG.** (The MLB artifact already declares `scoreline / first_scorer / xg / corners / cards` under `unavailableModules`.) They can be added later **only** when a real World Cup / soccer simulation artifact carries those fields — a soccer sim generator is not in scope here. Phase 5 adds a sport-dispatch shell with honest "soccer simulation dashboard will appear when a soccer artifact is ready" copy — no fake soccer data.

## Honesty invariants (every module)
`runCount` "1,000-run" copy only when `allowsRunCountClaim`; no "10,000"; no "Monte Carlo"; distributions only from real bins; market-agreement labelled **current-slate** (not long-term calibration) unless it uses settlement data; no banned copy (lock/guaranteed/safe/…); static-export safe (server loads, client animates); same output for every user; paper-only.
