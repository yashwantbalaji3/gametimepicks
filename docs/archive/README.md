# docs/archive

Preserved historical and generated material. **None of this is the source
of truth** — the canonical docs ([`../README.md`](../README.md)) + the live
repo are. Archived material is kept for history, traceability, and
acquisition diligence.

## Layout

- [`historical-handoffs/`](./historical-handoffs/README.md) — catalog of the
  dated handoff docs (which remain at their original `docs/` paths to avoid
  churn / broken links). See [`../HANDOFF_INDEX.md`](../HANDOFF_INDEX.md).
- [`generated-reference/`](./generated-reference/README.md) — clean Markdown
  copies of externally-generated reference material (ChatGPT handoff, the
  end-to-end PR record). Point-in-time; superseded.

## What is intentionally NOT committed

- Binary `.docx` duplicates of the Markdown references (redundant).
- Repo-snapshot `.zip` archives (trust the live repo).
- Any credentials, API keys, secrets, or local scratch files.
