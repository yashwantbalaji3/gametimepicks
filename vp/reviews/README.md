# reviews/

Department review outputs — the merged findings from parallel audits (Product, UX, Quant, QA, Data, Ops, Launch, CX). Each review ends with a prioritized fix list (impact × effort × risk) and a recommended Claude Code prompt.

Naming: `YYYY-MM-DD-topic.md` (e.g. `2026-07-08-launch-readiness-sweep.md`).
