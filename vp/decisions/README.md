# decisions/

Dated decision log (ADR-style). Every non-trivial product/strategy/model call gets a short record: **context → options → decision → why → consequences**. This is how we stop re-litigating settled debates.

Naming: `NNNN-short-slug.md` (e.g. `0002-activate-ladder-v2.md`).
Status values: `proposed` · `accepted` · `superseded` · `deferred`.

Start here: `0001-OPEN-STRATEGIC-DECISIONS.md` — the decisions currently awaiting Yash.
