# GameTime Picks — AI Employees

*The agent roster for the AI-operated company. Two **line departments** produce the product and the
audience; a **shared-service** function pool serves both; **Claude Code** is the execution engine; the
**founder** holds the four gates. Full model: [docs/AI_COMPANY_OPERATING_SYSTEM.md](../docs/AI_COMPANY_OPERATING_SYSTEM.md).*

## Org chart

```
  │       Discord · Instagram · TikTok · X/Twitter (ACTIVE) · Repurposing · Community (STANDBY)
  │
  └── SHARED SERVICES (function pool — either department requisitions on demand)
        Product Manager · QA Engineer · Data Engineer · Launch Manager · UI/UX Designer · Content Analyst · Quant

Claude Code — execution engine (runs the mutations every department hands it).
Claude Chat / GPT — advisory (strategy + prompt-crafting).
```

## How it composes
- **Line departments** (Sports Ops, Social/Growth) own the daily output — settlement + generation + cards, and content + audience.
- **Shared services** are *functions*, not a department: Product, QA, Data, Launch, UI/UX, Content, and Quant are requisitioned by whichever department needs them (and report to the VP for functional direction).
- **Claude Code is execution, not autonomous strategy** — it runs scripts, gates, and deploys that the departments (via Cowork) sequence; it never invents a card, a result, a sequence, or a public post.
- The **founder** holds the four gates: cards · model-weight changes · deploy/ship · public brand/posts.
